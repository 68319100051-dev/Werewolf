# Pixel Werewolf — เอกสารออกแบบเกม (เวอร์ชันพื้นฐาน)

## แนวคิด
เกมแววูฟพิกเซล เล่นออนไลน์กับเพื่อน 4–12 คน ขับเคลื่อนด้วยการ์ด
ผู้เล่นไม่ต้องเดินเอง: เลือกการ์ดสถานที่ แล้วตัวละครเดินไปเองแบบอนิเมชั่น
ภาพทั้งหมดเป็นพิกเซลอาร์ต (ไม่ใช้อีโมจิ) มีคัตซีนในจังหวะสำคัญ

## รอบเกม
เริ่มเกมที่กลางวันวันที่ 1 (ข้ามประชุมรอบแรก)

1. **กลางวัน** — จั่วการ์ดสถานที่ 3 ใบ เลือก 1 ใบ เปิดพร้อมกัน
   - เห็นว่าใครอยู่สถานที่เดียวกับตัวเอง (ไม่เห็นสถานที่อื่น)
   - การ์ดที่ทำสำเร็จเติมหลอดเควสรวม
   - จ่าฝูงซุ่มโจมตีในป่าลึกได้
2. **กลางคืน** — จ่าฝูงเลือกเหยื่อ 1 คน / อาชีพพิเศษใช้พลัง
3. **เช้า (ประชุม)** — คัตซีนเปิดเผยคนตาย, คุย (พิมพ์ + ไมค์), โหวตแขวน 1 คน

## สถานที่ (5 แห่ง)
| สถานที่ | แต้ม | หมายเหตุ |
|---|---|---|
| ป่าลึก | 3 | อันตราย จ่าฝูงซุ่มได้ |
| บ่อน้ำ | 2 | |
| ทุ่งนา | 2 | |
| โบสถ์ | 1 | |
| โรงเตี๊ยม | 1 | ได้ข่าวลือ 1 ข้อ / เปลี่ยนชุดได้ |

## ชีวิตและการซุ่มโจมตี
- ทุกคนมี 2 ชีวิต เจ็บ 2 ครั้ง = ตาย
- กลางวันจ่าฝูงทำให้เจ็บได้ (ไม่ตาย) วันละ 1 ครั้ง ในป่าลึก เลือกเหยื่อได้แม้มีหลายคน
- ถ้ามีหมาป่าปกติอยู่ในป่าด้วย = รุมฆ่า เหยื่อตายทันที
- จ่าฝูงตีโดนหมาป่าปกติ: หมาป่าปกติเจ็บ และทั้งคู่รู้จักกัน (ห้ามตีซ้ำ)
- คนเจ็บสุ่มได้การ์ดเบาะแส 1 ใบ (อิงชุดของคนร้าย)
- กลางคืนจ่าฝูงฆ่าได้ทันที (ยกเว้นหมอปกป้อง)

## อาชีพ (เวอร์ชันแรก 7 อาชีพ)
| อาชีพ | ฝ่าย | พลัง |
|---|---|---|
| จ่าฝูง | หมาป่า | ซุ่มในป่า / เลือกเหยื่อกลางคืน / สั่งโหวตลับ |
| หมอดู | ชาวบ้าน | กลางคืนส่อง 1 คนว่าเป็นหมาป่าไหม |
| หมอ | ชาวบ้าน | กลางคืนปกป้อง 1 คน หรือรักษาแผล |
| นายพราน | ชาวบ้าน | ถ้าโดนซุ่ม จ่าฝูงเจ็บแทน |
| นักสืบ | ชาวบ้าน | รู้ว่าใครเปลี่ยนชุด / กลางคืนสอบปากคำลับ 1 คน (ห้ามซ้ำติดกัน) |
| คนบ้า | กลาง | ชนะถ้าโดนโหวตแขวน |
| ชาวบ้าน | ชาวบ้าน | การ์ดได้แต้ม +1 |

หมาป่าปกติ (วง 7+ คน): กลางวันเหมือนชาวบ้าน, กลางคืนได้ยินเสียงหอนบอกเหยื่อ, ได้คำสั่งโหวตจากจ่าฝูง
ถ้าจ่าฝูงตาย หมาป่าปกติ 1 ตัวขึ้นแทน

## การสุ่มโรล
- จ่าฝูง 1 ตัวบังคับ ที่เหลือสุ่ม (อาจเป็นชาวบ้านหมด)
- อาชีพพิเศษอย่างละไม่เกิน 1, ฝ่ายกลางไม่เกิน 1 (วง 4–6 คน)
- หมาป่าเพิ่มเฉพาะวง 7+ คน
- ไม่ประกาศว่าเกมนี้มีโรลอะไร

## เงื่อนไขชนะ
- ชาวบ้าน: โหวตจับจ่าฝูง (และหมาป่าทั้งหมด) ได้ หรือหลอดเควสเต็ม
- หมาป่า: จำนวนหมาป่า >= คนที่เหลือ
- คนบ้า: โดนโหวตแขวน (จบเกมทันที)

## การแต่งตัวและเบาะแส
ส่วนที่แต่งได้: หมวก / สีผม / สีเสื้อ / ของติดตัว (อย่างละ 3–4 แบบ ให้ซ้ำกันได้)
เบาะแสบอก 1 ส่วนของชุดคนร้าย บางใบคลุมเครือ (เช่น "เสื้อสีเข้ม")
เปลี่ยนชุดได้ที่โรงเตี๊ยม คนที่อยู่ด้วยเห็น และนักสืบรู้เสมอ

## ประชุมและเสียง
| ช่วง | คนเป็น | คนตาย |
|---|---|---|
| ห้องรอ | พูด + พิมพ์ | — |
| ประชุม | พูด + พิมพ์ | ฟังอย่างเดียว |
| กลางวัน / กลางคืน | ปิด | คุยกันในห้องผี |
| สรุปผล | ทุกคน | ทุกคน |

ไมค์: กดค้างเพื่อพูด (ค่าเริ่มต้น) หรือเปิดตลอด

## ระบบนอกเกม
- หน้าแรก → ล็อกอิน (ชื่อเล่นก่อน, Google/Discord ทีหลัง) → เมนูหลัก
- ห้องแต่งตัว (สุ่ม/บันทึก)
- รายการห้อง, เข้าด้วยรหัสห้อง, ห้องล็อกรหัสผ่าน, ห้องซ่อน
- ตั้งค่าห้อง: ชื่อ, รหัส, ผู้เล่นสูงสุด, เวลาประชุม/เลือกการ์ด, อาชีพที่เปิด, เปิดเผยโรลคนตาย, ห้องผี, เปลี่ยนชุด, ความยาวหลอด, โหมดเสียง
- ห้องรอ: พร้อม, เตะ, โอนเจ้าของห้อง, ลิงก์เชิญ
- สรุปผล: เปิดโรลทุกคน, ไทม์ไลน์, รางวัล, เล่นอีกรอบ
- หลุดแล้วกลับเข้าห้องเดิมได้

## เทคโนโลยี
- เกมบนเว็บ: Phaser (client) + Node.js + Socket.io (server)
- เสียง: WebRTC
- ภาพพิกเซลวาดด้วยโค้ด แยกไฟล์ไว้ให้เปลี่ยนเป็นภาพศิลปินทีหลังได้

## แผนการสร้าง
1. โครงเกม + ระบบห้อง
2. เกมเพลหลัก
3. ภาพพิกเซล + อนิเมชั่น + คัตซีน
4. ห้องแต่งตัว + เบาะแส + นักสืบ
5. ไมค์ + เสียง + สรุปผล
6. ล็อกอินจริง + เอาขึ้นออนไลน์

## โหมดขั้นสูง (เก็บไว้ทีหลัง)
อาชีพ: คนเฝ้ายาม, นักเล่าข่าว, คนเลี้ยงหมา, ทหารยาม, นักบวช, ชาวนา, คนตัดไม้, เจ้าของโรงเตี๊ยม, สัปเหร่อ, หมาป่าเงา, หมอผี, คนทรยศ, โจร, แม่มด, กามเทพ
สถานที่เพิ่ม: โรงตีเหล็ก, สุสาน
ระบบ: การ์ดผลพิเศษตามอาชีพ, ไอเทม (ขวานเงิน, กุญแจ, สมุนไพร)
